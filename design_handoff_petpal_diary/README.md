# Handoff: PetPal Diary 寵物生活紀錄 — 手機 App

## Overview
PetPal Diary 是一款給**第一次養寵物的新手**使用的 iOS／Android App。支援狗、貓、兔、鳥、爬蟲、水族、小型哺乳類，提供多語系介面：繁中、简中、English、日本語、Español。

核心能力：
- 每日照護清單（多位家人分工）
- 健康紀錄（餵食、症狀、用藥、成長、提醒）
- 散步與活動計時
- 共享日記：照片上傳，社群分享到 LINE／FB／Threads／IG／WhatsApp，邀請親友共同編輯
- 新手知識庫、附近醫院與社群
- 16 項延伸工具，包含 AI 健康助理（可串接使用者自己的 ChatGPT／Gemini／Claude）、緊急求助、走失協尋等

## About the Design Files
本資料夾內的 HTML 檔是**設計參考原型**，用來呈現預期的外觀與互動，**不是可直接上線的程式碼**。

工程師的任務是在目標技術架構中**重新實作**這些設計。目前沒有既有程式碼庫，建議選用 **React Native（Expo）** 或 **Flutter**，理由：
- 需要推播、背景定位、藍牙、相機等原生能力。
- 需同時上架 iOS 與 Android。

原型使用專案自訂的「Design Component」格式（`.dc.html`）：
- 模板中 `{{ }}` 是資料插槽。
- `<sc-for>` / `<sc-if>` 是迴圈與條件。
- `class Component` 內的 `renderVals()` 是畫面邏輯。

實作時請把 `renderVals()` 視為「每個畫面的 view-model」參考，資料結構可直接沿用。

開啟方式：在瀏覽器打開 `PetPal Diary v2.dc.html`（需與 `support.js` 等檔案放在同一資料夾，用本機伺服器開啟，例如 `npx serve`）。

## Fidelity
**High-fidelity（高保真）**。顏色、字體、圓角、間距、文案、互動與驗證規則皆為最終設計，請依原型精確還原。

## 統一表單架構（重要）
所有紀錄表單由 `petpal-data.js` 的 `FORMS` schema 驅動，共用同一個表單元件渲染。表單有：feed、health、growth、reminder、diary、contact。

```js
{ id, title, desc, color, submit, toast, target?, tip?, fields:[
  { id, kind, label, options?, def?, required?, showIf?(v), hint?(v), validate?(v), dyn?(v), step?, min?, unit?, decimals?, ph?, inputMode?, max? }
], summary(v, t, val) }
```

- **欄位種類**：`segment`（單選）、`chips`（多選）、`stepper`、`text`、`textarea`、`date`、`toggle`、`photos`（最多 N 張，自動壓縮至長邊 900px、JPEG 0.72）。
- **欄位行為**：
  - `showIf` 控制欄位顯示；隱藏的欄位不驗證、不儲存。
  - `dyn` 讓欄位依其他值改變單位與步進，例如飲水時份量改成 ml、步進 50。
- **驗證**：送出時才顯示錯誤，錯誤欄位紅框 `#A0442A`。
  - 必填：「請填寫{欄位}」。
  - chips 必填：「請至少選一項」。
  - 電話格式：`/^[0-9+\-\s()]{6,}$/`。
- **其他規則**：
  - 「嚴重」症狀會顯示提示：請直接聯絡醫院。
  - 編輯模式：`openForm(id, entry)` 預填既有值；日記編輯會記錄 `editedBy`。

## 資料模型（`petpal-data.js` → `seed()`，`VERSION = 3`）
```
store = {
  v, liked{}, saved{}, posts[],
  members[{id, role: roleOwner|roleEditor|roleViewer}],
  journal[{id, author, petId, at, likedBy[], editedBy?, v:{mood, acts[], title, body, photos[], vis}}],
  pets: { [petId]: { week6[], tasks[{key,time,who,done}], entries[{id, form, at:"YYYY/MM/DD HH:MM", who, v}] } },
  tools: { ai, lost, expenses[], budget, meds[], doses{"日期|medId|時間": taken|skip}, docs[], supplies[], cart{}, groom{}, favPlaces{}, bookings[], devices{}, rsvp{}, hi{}, milestones[] }
}
```

- `entries.form` 可為：feed、health、growth、reminder、contact、activity。
- 可翻譯的種子內容存成 `{k:"翻譯鍵"}`，使用者輸入的內容存成純字串。顯示時統一用 `val()` 處理。
- **本機儲存**（localStorage）：
  - `petpal.store.v2`：整份 store。
  - `petpal.lang`：語言。
  - `petpal.prefs`：背景色與首頁排版。
  - `petpal.aikeys`：AI 金鑰，獨立存放，不隨 store 同步。
- **載入防護**：等資料檔載入（逾時自動重新注入），載入失敗顯示「重新載入」按鈕。版本不符或 JSON 損毀時清除並改用種子資料。正式版請以後端資料庫取代，並保留「版本檢查 + 遷移」。
- **權限**：
  - 擁有者／可編輯：可寫日記、編輯所有日記。
  - 僅檢視：只能看和按讚。
  - 刪除：作者本人或擁有者。
  - 私密日記只有作者看得到。

## 多語系
- 主字串：`petpal-data.js` 的 `U`，格式 `key: [繁中, 简中, English, 日本語, Español]`。
- 工具字串：`petpal-tools.js` 的 `RAW`，格式 `"繁|简|EN|日|ES"`。
- 插值格式：`{name}`；缺漏時退回繁中。
- 建議正式版改用 i18next（React Native）或 Flutter intl，可用腳本從這兩個檔案轉成 JSON。
- 字型需涵蓋 TC／SC／JP 字形。

|---|---|
| 地圖與友善地點 | Google Maps Platform／Mapbox＋Places API＋自建「寵物友善規定」資料庫（PostgreSQL＋PostGIS） |
| 走失附近通報 | 使用者模糊位置（geohash）＋半徑查詢＋FCM／APNs 推播＋目擊回報審核 |
| 保母預約與 GPS | 保母端 App、身分審核、金流（綠界 ECPay／TapPay／Stripe）、背景定位＋即時通道（Firebase／Supabase Realtime／WebSocket） |
| 智慧裝置 | 品牌開放平台（如 Tuya IoT）或 Matter／藍牙（原生）、攝影機用廠商 SDK 或 WebRTC |
| AI 助理 | 內建 AI 請由後端代理呼叫，不要把金鑰放在 App 內。使用者自帶金鑰模式可保留在裝置端安全儲存（Keychain／Keystore） |
| 共享日記與照片 | 帳號系統、雲端儲存（S3／Firebase Storage）、成員權限 |

建議開發順序：
1. 帳號 + 寵物檔案 + 照護清單 + 統一表單 + 多語系
2. 共享日記與分享
3. 健康工具（用藥、報告、文件、花費）
4. 地圖與走失通報
5. AI 助理
6. 保母平台
7. 智慧裝置

## Assets
- **寵物照片、日記照片、攝影機畫面**：皆為可拖放的圖片佔位（`image-slot.js`），正式版改為使用者上傳或相機拍攝。
