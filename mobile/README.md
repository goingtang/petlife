# PetPal 手機 App

PetPal 寵物生活紀錄的手機版（iOS／Android），用 Expo（React Native）開發。資料都存在手機裡，不需要網路也能使用。

## 在手機上測試（Expo Go）

需要一台電腦（Mac 或 Windows）安裝 [Node.js](https://nodejs.org/)（選 LTS 版）。

```bash
git clone https://github.com/goingtang/petlife.git
```

```bash
cd petlife/mobile
```

```bash
npm install
```

```bash
npx expo start
```

畫面上會出現 QR Code：

- **iPhone**：用內建「相機」掃描，點通知開啟 Expo Go。
- **Android**：打開 Expo Go，按「Scan QR code」掃描。

手機和電腦要連同一個 Wi-Fi。如果連不上，改用 `npx expo start --tunnel`。

第一次開啟可以選「使用範例資料」，所有功能都能直接操作；之後到「更多 → 設定」可以清除範例資料。

## 功能

| 分頁 | 內容 |
|---|---|
| 今天 | 依真實日期顯示今日照護（每天自動重置）、下一件事、到期提醒、今天用藥、最近紀錄 |
| 日記 | 最近 7 天、依寵物篩選、照片（最多 4 張）、私密日記、分享、去年的今天 |
| 健康 | 體重變化圖（依實際日期）、疫苗與提醒（逾期／完成後自動排下一次）、看診紀錄與照片 |
| 活動 | 計時（離開 App 也繼續）、最近 7 天統計、補登、刪除 |
| 更多 | 16 項工具，見下表 |

| 工具 | 說明 |
|---|---|
| AI 健康助理 | 離線判斷緊急症狀；把寵物資料和症狀整理成提問，開啟 ChatGPT／Claude／Gemini 等 |
| 緊急求助 | 一鍵撥打主治醫院、找附近 24 小時急診、急救步驟、給醫院的資料 |
| 有毒查詢 | 20 種常見食物／植物／居家用品／藥物，依狗、貓、兔、鳥分級 |
| 走失協尋 | 產生協尋海報 PDF，分享到 LINE 群組 |
| 用藥打卡 | 排程、到時間通知、打卡、7 天服藥率 |
| 健康報告 | 產生 PDF 給獸醫 |
| 文件夾 | 拍照或上傳 PDF；到期前提醒 |
| 花費記帳 | 任意月份、依寵物篩選、圓餅圖、6 個月趨勢、匯出 CSV |
| 用品庫存 | 依每日用量自動扣庫存、快用完提醒、去蝦皮找 |
| 美容洗澡 | 自訂週期、逾期提醒 |
| 成分掃描 | 貼上飼料成分表，依關鍵字評分 |
| 照顧須知 | 給保母的說明，可分享文字或 PDF |
| 附近地點 | 依手機定位，從 OpenStreetMap 找附近的動物醫院、用品店、美容、狗公園 |
| 里程碑 | 自動整理生日、到家日、體重、完成的疫苗；可自訂並加照片 |
| 新手知識 | 7 篇入門文章、搜尋、收藏 |

另有：寵物新增／編輯／刪除、家人成員與「現在是誰在用」、每日照護項目與輪值、通知設定、備份匯出與還原。

## 目前的限制

- **家人同步**：資料只存在一支手機。多支手機即時同步需要雲端帳號與後端（例如 Firebase 或 Supabase）。
- **AI**：手機上沒有內建 AI，需要後端代為呼叫；目前改為整理提問後開啟使用者自己的 AI App。
- **App 內訂閱**：需要正式打包（EAS Build）並在 App Store／Google Play 設定，Expo Go 無法測試。
- **成分掃描拍照辨識**：Expo Go 沒有文字辨識模組，目前用貼上文字。
- **介面語言**：目前只有繁體中文。
