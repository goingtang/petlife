PetPal 寵物生活

一起照顧毛孩的每一天

PetPal 幫你記錄寵物的餵食、健康、疫苗與用藥，到時間在手機上提醒你；另有緊急求助、有毒查詢、走失協尋海報、花費記帳等工具。

不需要註冊帳號，所有資料都存在你的手機裡。

常見問題

換手機或重裝 App，資料會不見嗎？

資料只存在手機裡。請定期到「更多 → 設定 → 匯出備份」，把備份檔存到自己的雲端硬碟；新手機安裝後在同一頁選「從備份還原」。備份檔（.zip）包含資料、照片與文件；舊版的 .json 備份還原時不含照片。照片與文件合計超過 120 MB 時，只能先「只匯出資料」，照片請另外用相簿或雲端保存。

為什麼沒有收到提醒通知？

請確認：「設定」裡的通知已開啟、手機系統設定允許 PetPal 發送通知、省電模式沒有限制 PetPal。Android 手機在深度省電時，通知可能晚幾分鐘出現。用藥提醒會排到未來 7 天，超過一週沒打開 App 時，請打開一次讓提醒繼續排程。

「附近地點」找不到資料？

需要網路與定位權限。地點資料來自 OpenStreetMap 社群，部分地區資料可能不完整，也可以改用頁面下方的 Google 地圖搜尋。

症狀檢查可以取代看醫生嗎？

不行。症狀檢查只提醒常見的緊急警訊，「問 AI」的回答也只供參考。寵物狀況有疑慮時請盡快就醫。

如何刪除所有資料？

到「更多 → 設定 → 清除所有資料」，或直接移除 App。我們沒有伺服器，所以沒有其他地方保存你的資料。
